# LuiYang08.github.io
个人博客 GitHub Pages 部署仓库
使用的模版是[hexo-theme-aurora](https://github.com/auroral-ui/hexo-theme-aurora)

## 简介
本仓库是我的**个人博客**源码仓库，基于 GitHub Pages 进行静态博客部署，在线访问：
👉 [https://LuiYang08.github.io](https://LuiYang08.github.io)

博客主要用于记录学习笔记、技术分享、生活随笔、经验总结等内容，长期持续更新维护。

## 仓库目录结构
```
├── api/         # 接口相关静态资源
├── archives/    # 文章归档页面
├── icons/       # 图标资源文件
├── img/         # 博客图片静态资源
├── page/        # 独立页面
├── post/        # 博客文章正文
├── static/      # 全局静态资源(JS/CSS等)
├── svg/         # SVG 矢量图标
├── tags/        # 标签分类页面
├── favicon.ico  # 网站图标
└── index.html   # 博客首页入口
```

## 技术栈
- 整体语言：**HTML 100%**
- 部署平台：**GitHub Pages**
- 类型：静态个人博客

## 更新说明

- 最新站点更新时间：`2026-05-02 16:31:50`
